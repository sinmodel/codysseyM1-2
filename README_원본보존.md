# AI 주식 도우미 — 자동 점검 UI 초안

## 로컬 실행
1. 프로젝트 폴더에서 터미널을 엽니다.
2. 가상환경을 활성화합니다.
3. `pip install -r requirements.txt`
4. `python -m uvicorn app.main:app --reload`
5. `http://127.0.0.1:8000/` 접속

## 추가된 기능
- 테스트용/실제용 전환 메뉴
- 실제용 백엔드 HTTPS 주소 설정
- `/api/health` 연결 확인
- 브라우저 수준의 자동 점검 및 노트북 준비 체크리스트
- HTTP 상태 코드별 오류 안내
- 다시 실행하기 버튼
- 기존 그래프/기간 선택/추세 분석 보존

## 제한과 다음 작업
브라우저 보안상 웹페이지는 Python 설치 여부, OS 설정, 로컬 패키지를 직접 읽거나 변경할 수 없습니다. 이 항목들은 사용자 체크리스트로 안내합니다.
현재 백엔드는 메모리 저장 방식이며 Firestore와 OpenAI 채팅 API는 아직 추가되지 않았습니다. 실제용으로 배포하기 전에 구현해야 합니다.
가격 데이터는 교육용 시뮬레이션 데이터입니다. `.env`와 Firebase 서비스 계정 파일을 Git 또는 프런트엔드에 올리지 마세요.
